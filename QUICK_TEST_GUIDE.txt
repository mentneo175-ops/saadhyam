⚠️ COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════

Issue: "Connection refused" or "Cannot connect to localhost:8000"
Fix:   Start backend: cd Backend && python main.py

Issue: "health endpoint returns 'degraded'"
Fix:   Check database connection, Firebase credentials, Pinecone API key

Issue: "Rate limiting not working"
Fix:   Make sure slowapi is installed: pip install slowapi

Issue: "Smart analysis service import fails"
Fix:   Verify all files are in place: Backend/services/smart_analysis_service.py

Issue: "Health endpoints return 500 error"
Fix:   Check backend logs for specific errors

💡 PRO TIPS
═══════════════════════════════════════════════════════════════════

• Use browser to test: http://localhost:8000/health/
  Will show JSON response with formatting

• Monitor logs while testing:
  tail -f logs/backend.log
  (In another terminal)

• Test from another machine to verify network:
  curl http://<your-ip>:8000/health/

• Use: curl -v to see full HTTP response details

• Add -i to curl to include response headers:
  curl -i http://localhost:8000/health/
