Gaps / Missing production-level pieces
--------------------------------------
1. API Keys & External Services configuration:
   - `GEMINI_API_KEY` (and optional GEMINI_API_KEY_2/3) required for real LLM generation.
   - `PINECONE_API_KEY` and Pinecone client library (`pinecone-client`) must be installed and configured to enable semantic vector store and search.
   - Google Search grounding and SERP APIs (SERPAPI / TAVILY / custom) are referenced but need keys and quotas.
2. Real AI visibility scraping / engine APIs:
   - `ai_visibility_tracker` currently generates mock mentions. Production tracking requires engine-specific connectors or scraping + rate-limit/consent handling.
3. Content publishing integrations:
   - Endpoints exist for blog publish, but real site publishing requires configured `WORDPRESS_API_*`, `MEDIUM_API_TOKEN`, or other platform connectors; `Website AI` flow must be configured and the user must create a website before publishing.
4. Scheduled automation and background tasks:
   - `AEO_GEO_AUTO_OPTIMIZATION` exists, but automation requires scheduled workers (Celery/cron) to run discovery, generation and tracking loops.
5. Monitoring, metrics & validation:
   - Schema validation and submission to Google (Search Console) not implemented.
   - Rank tracking and ROI metrics missing (SERP position tracking, conversion metrics).
6. Content distribution automation (social posting, syndication) has placeholder models and DB support but not end-to-end publishers.
7. Tests and CI: limited automated tests for these flows; more unit/integration coverage needed.
8. Migrations: migration script `migrations/add_aeo_geo_tables.py` exists, ensure migrations run to create AEO/GEO tables.
