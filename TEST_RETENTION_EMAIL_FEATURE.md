## 🚨 Troubleshooting

### **Issue: "Failed to send retention email"**

**Possible Causes:**
1. Invalid email address
2. Gemini API error
3. Resend API error
4. Network connectivity issue

**Solutions:**
- Check email format is valid
- Verify GEMINI_API_KEY in Backend/.env
- Verify RESEND_API_KEY in Backend/.env
- Check backend logs for detailed error
- Try again in a few seconds

---

### **Issue: Button stays on "Sending..."**

**Cause:** Backend request timeout or error

**Solution:**
- Check backend is running (port 8000)
- Check backend logs for errors
- Refresh the page and try again
- Verify API keys are correct

---

### **Issue: Email not received**

**Possible Causes:**
1. Email went to spam folder
2. Resend test domain limitations
3. Invalid email address

**Solutions:**
- Check spam/junk folder
- Verify email address is correct
- Check Resend dashboard for delivery status
- Note: Resend test domain may have limitations

---

### **Issue: "Customer must be inactive for at least 30 days"**

**Cause:** Customer has inactive_days < 30

**Solution:**
- Only customers with 30+ inactive days can receive emails
- This is by design to prevent spamming active customers
- Check the "Inactive Days" column in the table
