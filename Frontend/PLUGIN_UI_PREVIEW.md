## 🎬 User Journey

1. **Land on Page**
   - See header with stats
   - View all plugins by default
   
2. **Explore Categories**
   - Click category filter
   - See filtered plugins
   - Count updates

3. **Search**
   - Type in search box
   - See instant results
   - Clear to reset

4. **View Details**
   - Click "Details" button
   - Modal opens
   - See full information

5. **Install**
   - Click "Install" button
   - Toast notification shows
   - Plugin activates
