# LinkedIn Marketing Plugin

This is a scaffold for a LinkedIn Marketing plugin that follows the existing Saadhyam plugin architecture.

## Current behavior
- Provides a configurable plugin entry for installation and setup
- Supports a placeholder campaign creation workflow
- Does not implement live LinkedIn API calls yet

## Files
- `main.py` - plugin entrypoint and action implementations
- `manifest.json` - marketplace metadata for the plugin
- `__init__.py` - package marker
