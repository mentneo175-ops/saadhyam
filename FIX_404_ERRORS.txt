═══════════════════════════════════════════════════════════════
  THE PROBLEM
═══════════════════════════════════════════════════════════════

Frontend is getting 404 errors for:
❌ GET /api/aeo-geo/overview → 404 Not Found
❌ GET /api/blogs/?limit=50&offset=0 → 404 Not Found

But the routes EXIST in the backend code!

═══════════════════════════════════════════════════════════════
  WHY THIS HAPPENS
═══════════════════════════════════════════════════════════════

The backend server needs to be restarted after:
1. Database migration (add_privacy_sharing.py)
2. Error handler updates (ExceptionGroup handling)
3. Main.py changes (h11 error handling)

The routes are registered but the old server process
is still running with the old code.

═══════════════════════════════════════════════════════════════
  THE SOLUTION
═══════════════════════════════════════════════════════════════

RESTART THE BACKEND SERVER

Windows:
1. Stop: stop_all.bat
2. Wait 5 seconds
3. Start: start_all.bat

Linux/Mac:
1. Stop: ./stop_all.sh
2. Wait 5 seconds
3. Start: ./start_all.sh

═══════════════════════════════════════════════════════════════
  COMMON ISSUES
═══════════════════════════════════════════════════════════════

Issue 1: Port Already in Use
Solution: Kill the process
  Windows: taskkill /F /IM python.exe
  Linux: pkill -f uvicorn

Issue 2: Virtual Environment Not Activated
Solution: Activate venv
  Windows: Backend\venv\Scripts\activate
  Linux: source Backend/venv/bin/activate

Issue 3: Missing Dependencies
Solution: Reinstall
  pip install -r Backend/requirements.txt

Issue 4: Database Connection Error
Solution: Check .env file
  DATABASE_URL should be set correctly
