The demo assistant uses **keyword matching** to understand queries:

### Pattern Examples:

**Company Detection:**
```python
if "amazon" in query.lower():
    company = DEMO_COMPANIES["amazon"]
```

**Strengths Detection:**
```python
if any(word in query for word in ["strength", "strong", "advantage"]):
    return strengths_response
```

**Comparison Detection:**
```python
if "compare" in query or "vs" in query:
    return comparison_response
```

## 🐛 Troubleshooting

### Issue: "I encountered an error"
**Solution**: 
- Backend is now using demo mode (no auth required)
- Restart backend if needed
- Check backend logs

### Issue: No response
**Solution**:
- Check backend is running on port 8000
- Check frontend is running on port 8080
- Try asking about specific company: "Tell me about Amazon"

### Issue: Generic response
**Solution**:
- Be specific: Instead of "Tell me more", say "What are Amazon's strengths?"
- Mention company name in your question
- Use keywords like "strengths", "weaknesses", "products"
